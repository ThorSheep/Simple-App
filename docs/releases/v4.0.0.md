# Simple App v4.0.0

## 自託管跨裝置同步

這個版本新增自託管同步功能。你可以將同步伺服器架設在自己的電腦、NAS 或 VPS，讓不同裝置同步資料，而不需要使用官方雲端。

- 支援記帳、課程、上課時段、待辦、公告訂閱與公告關鍵字同步。
- 支援離線後補傳與跨裝置同步。
- App 主要頁面可下拉立即同步。
- 支援背景同步。
- 伺服器採 Docker Compose、SQLite 與 HTTPS 部署。
- 每台裝置需使用配對碼取得獨立憑證。

## 升級提醒

- 自託管同步是選用功能；不設定伺服器時，App 仍會維持原本的離線使用方式。
- 同步前建議先匯出 JSON 備份。
- 請依照專案中的 `server/README.md` 部署自己的同步伺服器。
