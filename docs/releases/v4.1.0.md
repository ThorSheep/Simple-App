# Simple App v4.1.0

## 同步體驗改善

- 修改收支、課程、待辦、公告訂閱或關鍵字後，App 會在有網路時自動上傳；離線變更會保留並在網路恢復後重試。
- App 在前景時，若其他已配對裝置成功上傳新資料，會顯示「其他裝置有新資料，請下拉重新整理同步」提示。
- App 從背景回到前景時會自動同步一次；背景或關閉期間不使用第三方推播服務。

## 修正

- 側邊選單與設定頁的版本資訊改為讀取實際 App 版本，不再錯誤顯示 `3.1.0`。

## 升級提醒

- 若使用自託管同步，請將伺服器更新為本版附帶的程式後重新執行 Docker Compose 建置；既有 SQLite 資料與已配對裝置會保留。
- 自動同步與前景通知均為選用同步功能的一部分；未設定同步伺服器時，App 仍可離線使用。
