# Simple App v5.1.0

## ee-class Gmail 自動匯入

- 新增選用的 Gmail 自動匯入：只讀取使用者授權的 `eeClass` 標籤中、由 `eeclass@ncu.edu.tw` 寄出的作業通知。
- 支援從作業開放與截止提醒建立或更新重要作業待辦；收到繳交完成通知時可標記既有待辦完成。
- Gmail 匯入與 ee-class 瀏覽器擴充功能會辨識同一課程的相同作業並更新同一筆待辦，避免重複。

## 匯入確認與安全

- 新增受 setup token 保護的 Gmail 匯入狀態頁，可確認伺服器是否列出、驗證與辨識信件，且不顯示信件內容。
- 可從狀態頁手動重新掃描 `eeClass` 標籤，不需要等待定期檢查。
- 不使用 Gmail 密碼、IMAP、Gmail MCP 或 AI，也不保存信件全文；只有 Gmail 訊息 ID 用於去重。
