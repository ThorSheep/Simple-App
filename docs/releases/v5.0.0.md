# Simple App v5.0.0

## 個人管家 MCP Server

- 新增部署在自託管伺服器的唯讀 MCP Server，提供未完成事項、近期到期、今日行程與個人摘要工具。
- MCP 使用獨立 Bearer 憑證，與 App 裝置配對碼、同步憑證完全分離。
- 所有工具只會讀取已同步的課程與待辦資料；不能修改、建立或刪除資料。

## LINE 查詢與本機 AI

- LINE 官方帳號可透過 webhook 回覆 `今日行程`、`未完成作業`、`本週截止`、`摘要`和`說明`固定指令。
- LINE webhook 驗證 Channel secret，且只回覆使用者指定的 LINE User ID。
- 可選擇將自然語言問題交給同一台電腦上的 Ollama，讓本機模型呼叫相同的唯讀工具；未設定 Ollama 時，固定指令仍可正常使用。

## 部署與安全

- 新增 MCP、LINE webhook 與 Ollama 的 Docker 環境變數、單一伺服器與雙環境部署說明。
- 不會將 Channel access token、Channel secret、MCP 憑證、LINE User ID 或 Ollama 模型資料提交到 Git。
