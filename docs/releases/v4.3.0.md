# Simple App v4.3.0

## ee-class 作業匯入

- 新增 Chrome／Edge 擴充功能，可從中央 ee-class 課程的「作業」清單手動匯入待辦。
- 匯入前可查看作業名稱、截止時間與繳交狀態，並勾選本次要加入的作業。
- 可將 ee-class 課程對應到既有的 Simple App 課程；手動選擇一次後會在瀏覽器記住對應，未選擇時會建立未關聯待辦。
- 尚未繳交且尚未截止的作業會預設勾選；已繳交或過期作業仍可由使用者自行選擇。
- 支援「永久略過」與恢復略過，避免不需要的作業反覆出現。
- 匯入作業一律標示為重要事項；重複匯入同一作業會更新截止資料而不重複建立，並顯示新增與更新數量。
- 手機或平板的匯入待辦可直接開啟 ee-class 原始作業頁。

## 安全與同步

- 擴充功能只在使用者已登入的中央 ee-class 作業頁讀取頁面資料，不會讀取或保存 Portal 帳密、Cookie。
- 首次使用時以同步伺服器網址與配對碼為瀏覽器建立獨立裝置憑證；之後只透過該憑證同步。
- 匯入作業保留 ee-class 原始連結，手機、平板在同步後即可看到相同待辦。
