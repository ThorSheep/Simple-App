# Simple App v4.2.0

## LINE 提醒

- 新增獨立的「LINE 提醒」設定頁，不再與資料同步和版本資訊混在一起。
- 可開關每日摘要，選擇摘要時間，並決定是否包含今日課程、今日事項與明日事項。
- 可設定截止日前 7、3、1 天及當天的提醒時間。
- 通知由你自行架設的同步伺服器，以自己的 LINE 官方帳號發送；App 資料仍保留在你的伺服器。

## 同步伺服器切換

- 從測試環境切換到正式環境時，App 會清除舊伺服器的同步游標與待傳佇列，再由目前本機資料重新建立同步內容。
- 此程序不會刪除本機的收支、課程、待辦或設定；配對完成後會將它們同步到新伺服器。

## 使用方式

1. 將伺服器更新為本版的 Docker 設定並重新部署。
2. 在 App 的「LINE 提醒」頁設定並啟用提醒，然後同步一次。
3. 若原本連到測試伺服器，先中斷同步，再以正式網址與正式配對碼重新配對。
