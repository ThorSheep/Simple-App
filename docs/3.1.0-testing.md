# 3.1.0 測試清單

本版以 3.0.0 為基礎完成 issue #3 尚未完成的自訂功能與 App 內更新。詳細變更見 [CHANGELOG](../CHANGELOG.md)。

## 介面與設定

1. 在設定的「首頁」逐一開關本月收支、今日課程、近期事項、行事曆入口與公告，回到首頁確認顯示一致；以箭頭調整順序後重新開啟 App，順序應保留。
2. 在設定的「底部導覽」選擇至少兩個常用功能、調整其順序及首頁位置，確認底部列和切換結果一致。
3. 開啟左右滑動切換後，在畫面中央左右滑動，確認只會在已選底部功能間切換；關閉後滑動不切換。
4. 分別選擇跟隨系統、淺色與深色主題，重開 App 確認設定保留；匯出後再匯入備份，確認首頁、底部、手勢與主題設定都還原。
5. 在設定頁切換「介面」、「公告」及「資料與版本」，確認設定依分類顯示；在公告頁切換「公告內容」與「訂閱管理」，確認訂閱與更新操作只位於訂閱管理。

## App 更新

1. 安裝正式簽署的舊版 APK，開啟設定後確認會顯示可用的較新正式 Release；可關閉「啟動時檢查新版本」並以手動按鈕再次檢查。
2. 選擇下載更新，待下載完成後確認 Android 系統安裝器顯示目標版本，並由系統驗證同一簽章後覆蓋安裝。
3. Android 8 以上首次安裝時，若系統要求允許此 App 安裝未知來源，允許後回設定頁再次點選安裝。
4. 以 Android Studio 安裝 debug 版，確認設定顯示不支援 App 內更新；debug 與正式版可以同時安裝，資料彼此獨立。
5. 在沒有網路時檢查更新，確認顯示失敗訊息且不影響其他功能。

## 自動驗證

以本機 JDK 17 執行 `assembleDebug testDebugUnitTest lintDebug`。27 項測試涵蓋既有資料遷移、備份、公告通知、首頁／主題設定備份，以及 GitHub Release 資訊與 APK URL 驗證。
