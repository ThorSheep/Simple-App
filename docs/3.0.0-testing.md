# 3.0.0 測試清單

3.0.0 以 2.3.0（4f386c3）為基礎，新增課程、行程與公告自動更新功能。詳細變更見 [CHANGELOG](../CHANGELOG.md)。

## Android Studio

Gradle JDK 請使用 JDK 17 或 21；現有 Gradle 8.11.1 / Kotlin 2.1.20 不適用本機 Android Studio 內附的 Java 25。可選本機 `C:\Program Files\Java\jdk-17.0.2`。

Run 使用 debug variant，識別碼為 `tw.thorsheep.simpleapp.debug`，與正式 App 分開安裝。正式 App 資料可先匯出 JSON 再在測試版匯入。

## 驗收

1. 匯入 2.3.0 備份，核對記帳、課程、待辦關聯、完成狀態與公告訂閱。
   資料庫版本為 5，亦支援先前本機原型的資料庫版本 4，避免已安裝原型時發生結構衝突；備份格式版本仍為 4。
2. 在課程入口確認預設顯示課表；新增一門課並加入兩個不同星期的時段，確認各時段的教室與教師。
3. 切換課程清單，進入詳情新增作業、分組報告及考試。報告設定繳交與報告兩個日期，確認行程都有出現。
4. 編輯課程名稱與時段，確認事項仍關聯原課程；封存後不再排課。刪除課程後，其事項仍在待辦且解除關聯。
5. 待辦依課程、類型及完成狀態篩選；完成後從行程消失。檢查逾期提示。
6. 設定首頁顯示／隱藏今日課程、近期事項；點摘要可進入對應功能。底部最多四項，可加入行事曆／行程。
7. 行程頁拒絕日曆權限時仍顯示 App 事項。授權後勾選多個手機日曆，核對全天、重複、跨日事件與時區；切換分類、日期並返回 App，內容應重新讀取。手機日曆事件不匯入備份，也不被 App 修改。
8. 設定公告關鍵字，比對標題、單位及分類，確認英文大小寫不影響匹配；測試停用、刪除與只看命中。
9. 訂閱單位後先手動更新建立基準，再使用後續新公告測試通知。既有公告不補發，不因重複更新或快取清除而重複通知。拒絕通知權限仍可醒目顯示。
10. 分別設定自動更新 6／12／24 小時及關閉；設定頁查看最後更新時間與錯誤。背景排程不保證準時，Wi-Fi 選項實際限制 Android 的不計量網路。
11. 匯出 3.0.0 備份並還原，核對所有課程時段、報告分組與雙日期、關鍵字及設定。取消還原或載入損壞備份不應改變現有資料。

## 已知範圍

- 其餘公告來源仍依 README 已知問題處理，未在此版本重新啟用。
- 課程採每週固定時段，尚無學期起訖與停課例外。
- 日曆分類是 Android 提供的日曆／帳號清單，不包含各日曆 App 自訂且未公開給系統的標籤。
- App 顯示事項的日期與時間，尚無作業／考試到期提醒。
- 長期背景排程與手機廠商省電限制仍需實機測試。

## 自動驗證

使用本機 JDK 17 執行 `assembleDebug testDebugUnitTest lintDebug`。23 項測試涵蓋舊版及原型資料庫實際遷移、課程刪除與事項保留、舊／新備份、報告雙日期、關鍵字比對及公告通知基準與去重。測試在本機 JVM／Robolectric 執行，未將測試資料寫入手機。
