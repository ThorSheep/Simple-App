# ee-class 作業匯入擴充功能

此 Chrome／Edge Manifest V3 擴充功能只在中央大學 ee-class 的課程「作業」清單頁讀取作業名稱、截止時間、繳交狀態與作業連結。它不會讀取、保存或傳送 Portal 密碼與 ee-class Cookie。

## 本機安裝

1. 下載或 clone 此專案。
2. 在 Chrome 開啟 `chrome://extensions`，或在 Edge 開啟 `edge://extensions`。
3. 開啟右上角的「開發人員模式」。
4. 按「載入未封裝項目」，選擇這個 `extensions/eeclass-importer` 資料夾。
5. 正常登入 [中央 ee-class](https://ncueeclass.ncu.edu.tw/)，並開啟任一課程的「作業」清單頁。
6. 按瀏覽器工具列的「Simple App ee-class 作業匯入」圖示。
7. 第一次使用時輸入你的 HTTPS 同步伺服器網址與配對碼。瀏覽器會要求允許此擴充功能只連線到該伺服器。

配對成功後，擴充功能會取得自己的瀏覽器裝置憑證。配對碼只用於這次配對；不要將配對碼、瀏覽器憑證、Portal 帳密或 Cookie 寫入任何檔案或提交到 Git。

## 匯入規則

- 清單會顯示目前課程全部可辨識的作業。
- 預設只勾選「尚未繳交且尚未過期」的作業；你可以自行調整。
- 點「永久略過」後，該作業只會在這個瀏覽器隱藏，可在擴充功能底部的「已永久略過的作業」恢復。
- 匯入的 ee-class 作業會自動標示為重要事項；匯入使用固定的 ee-class 作業識別碼，因此在同一伺服器重複匯入不會建立重複待辦，而是更新同一筆待辦，並顯示本次新增與更新的數量。
- 手動選擇一次 Simple App 課程後，擴充功能會在此瀏覽器記住該 ee-class 課程的對應關係。
- 匯入後的待辦保留 ee-class 原始連結，可在 Simple App 待辦卡片直接開啟原作業頁。
- 作業先透過同步伺服器寫入，手機／平板下拉同步或回到前景後即可看到。

## 權限與限制

- 安裝時只允許讀取 `ncueeclass.ncu.edu.tw/course/homework` 頁面與儲存本機設定。
- 同步伺服器網址為可選權限，僅在你按下配對時申請該單一 HTTPS 網域。
- 不會背景輪詢 ee-class；只有你手動開啟擴充功能時才會讀取目前頁面。
- 第一版依 ee-class 的繁體中文「作業」表格欄位解析；學校改版後可能需要更新選擇器。
